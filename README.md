# quat2euler

[![test](https://github.com/s25c1021fxonagawa/robosys2026/actions/workflows/test.yml/badge.svg)](https://github.com/s25c1021fxonagawa/robosys2026/actions/workflows/test.yml)

標準入力から読み込んだクォータニオンを, オイラー角(roll, pitch, yaw)に変換して標準出力に出力するコマンドです.

## インストール

```
$ git clone https://github.com/s25c1021fxonagawa/robosys2026.git
$ cd robosys2026
```

Python 3の標準ライブラリだけで動くため, 追加のパッケージは不要です.

## 使い方

1行に1つのクォータニオンを`x y z w`の順で, 空白区切りで入力します.
1行につき`roll pitch yaw`を1行出力します.

```
$ echo "0 0 0.7071068 0.7071068" | ./quat2euler
0.000000 0.000000 1.570796
```

度数法で出力する場合は`-d`を付けます.

```
$ echo "0 0 0.7071068 0.7071068" | ./quat2euler -d
0.000000 0.000000 90.000000
```

複数行をまとめて変換できます.
小数点以下の桁数は`-p`で指定します.

```
$ printf '0 0 0 1\n1 0 0 0\n0.1 0.2 0.3 0.9\n' | ./quat2euler -d -p 2
0.00 0.00 0.00
180.00 0.00 0.00
19.44 18.41 40.05
```

### オプション

| オプション | 説明 |
| --- | --- |
| `-d`, `--degrees` | 度数法で出力する(省略時はラジアン) |
| `-p N`, `--precision N` | 小数点以下の桁数を`N`にする(`0`から`15`, 省略時は`6`) |
| `-h`, `--help` | ヘルプを表示する |

### 仕様

- 回転順はZ-Y-X(yaw, pitch, rollの順に回転)で, ROSのRPYと同じです.
- 入力が正規化されていない場合は, 正規化してから変換します.
- 出力する角度の範囲は, rollとyawが-π〜π, pitchが-π/2〜π/2です.
- pitchが±90度になる場合(ジンバルロック)は, rollを`0`として, yawに回転をまとめます.

### エラー

次の行はエラーとして, 標準エラー出力にメッセージを出し, 標準出力には何も出しません.
ほかの正しい行は変換を続けます.

- 数値が4つでない行(空行を含む)
- 数値でない値を含む行
- `nan`, `inf`を含む行
- すべての要素が`0`の行

```
$ printf 'a b c d\n0 0 0 1\n' | ./quat2euler
quat2euler: line 1: not a number
0.000000 0.000000 0.000000
```

### 終了ステータス

| 値 | 意味 |
| --- | --- |
| `0` | 正常終了 |
| `1` | 変換できない行があった |
| `2` | オプションが不正 |
